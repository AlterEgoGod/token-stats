# TokenStats

Приложение для Windows, которое показывает остаток лимитов Codex в трее и компактном виджете.

## Установка и запуск

Нужны Windows 10/11, .NET Framework 4.8 и установленный Codex с выполненным входом через ChatGPT.

- [**TokenStats-Setup.exe**](https://github.com/AlterEgoGod/token-stats/releases/latest/download/TokenStats-Setup.exe) — установка с ярлыками в меню «Пуск» и на рабочем столе. Удаление — через «Установленные приложения» Windows.
- [**TokenStats.exe**](https://github.com/AlterEgoGod/token-stats/releases/latest/download/TokenStats.exe) — запуск без установки.

Перед установкой или заменой файла закройте TokenStats через меню трея. Если требуется вход, нажмите «Войти через ChatGPT», затем обновите лимиты.

Если Codex не найден, создайте рядом с приложением файл `codex-path.txt` и укажите в нём полный путь к `codex.exe`.

## Возможности

- Остаток пятичасового и недельного лимитов, даты и время сброса.
- Автоматическое обновление данных и повторные попытки при потере связи.
- Компактный и развёрнутый виджет, перетаскивание и прилипание к краям экрана.
- Светлая и тёмная темы вслед за настройками Windows.
- Русский и английский языки, переключение через меню трея.
- Автозапуск с Windows и закрепление поверх других окон.

Нажатие на значок трея открывает виджет, правая кнопка — меню настроек. Приложение показывает процент оставшейся квоты, а не количество токенов.

## Обновления

Выберите «Проверить обновления» в меню трея. Приложение проверяет новые версии в [GitHub Releases](https://github.com/AlterEgoGod/token-stats/releases) и предлагает установить обновление.
