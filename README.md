# TokenStats

Готовое приложение для Windows: лимиты Codex в трее и компактном виджете. Версия **1.0.1**.

## Что нужно для работы

- `TokenStats.exe` — единственный обязательный файл приложения.
- Windows 10/11 с .NET Framework 4.8.
- Установленный Codex и выполненный вход через ChatGPT.
- Интернет для получения лимитов и проверки обновлений.

Приложение показывает процент оставшейся квоты Codex, а не точное количество токенов и не лимиты обычных чатов ChatGPT.

## Запуск

1. Скачайте ZIP-архив или `TokenStats.exe` из [последнего релиза](https://github.com/AlterEgoGod/token-stats/releases/latest). Либо на странице репозитория выберите **Code → Download ZIP** и распакуйте архив в постоянную папку. Можно также скачать отдельно `TokenStats.exe` через кнопку скачивания файла на GitHub.
2. Запустите **TokenStats.exe**. Сборка и установщик не нужны.
3. Найдите иконку возле часов; она может быть скрыта под стрелкой значков трея.
4. Нажмите на иконку → **Подробнее**. Если требуется вход, нажмите **Войти через ChatGPT**, завершите вход и выберите **Обновить лимиты**.

Если Codex не найден автоматически, создайте рядом с EXE файл **codex-path.txt**. Впишите в него полный путь к вашему `codex.exe` одной строкой, затем перезапустите TokenStats. Этот файл нужен только при проблеме с автоматическим обнаружением.

## Использование

- Цифры в трее и основной показатель виджета показывают остаток **недельного лимита для ChatGPT Business Premium**, для остальных подписок — пятичасового. Тариф определяется автоматически по данным Codex; обновление каждые **30 секунд**.
- Фон иконки прозрачный. Цифры чёрные при светлой системной теме Windows и белые при тёмной.
- Нажатие на иконку открывает компактный виджет. Кнопка **Подробнее** разворачивает его: оба периода, даты сброса, состояние обновления и кнопка входа. В большом окне порядок всегда одинаковый: сначала пятичасовой лимит, затем недельный. Если выбранный период отсутствует в ответе Codex, вместо процента отображается прочерк.
- **Свернуть** возвращает компактный вид. Перетаскивание мышью перемещает виджет; нажатие на фон ничего не открывает.
- Нажатие вне виджета скрывает его, если не включён режим **Всегда показывать виджет**.
- `?` в трее или прочерк в виджете означают отсутствие актуальных данных. Причину можно посмотреть в подробностях.

## Меню правой кнопки

| Пункт | Действие |
| --- | --- |
| Всегда показывать виджет | Оставлять виджет открытым и показывать его при запуске |
| Поверх остальных окон | Включить или отключить закрепление |
| Размер виджета | Маленький, средний или большой |
| Вернуть виджет к трею | Вернуть его в правый нижний угол рабочей области |
| Запускать вместе с Windows | Включить или отключить автозапуск |
| Проверить обновления | Найти новую версию на GitHub |
| Выход | Завершить приложение |

Положение, размер и настройки сохраняются для текущего пользователя. После включения автозапуска не перемещайте EXE. Если переместили — выключите и снова включите автозапуск из новой папки.

## Обновление

Выберите **Проверить обновления**. Приложение ищет новую версию в [GitHub Releases](https://github.com/AlterEgoGod/token-stats/releases), проверяет контрольную сумму и версию EXE и предлагает установить её с перезапуском. Нужен доступ на запись в папку приложения.

Если релиз ещё не опубликован, обновление не будет найдено. Для обновления вручную выберите **Выход**, скачайте новый `TokenStats.exe`, замените старый файл и запустите его снова.

## Удаление

Выключите **Запускать вместе с Windows**, выберите **Выход** и удалите `TokenStats.exe`. Необязательный `codex-path.txt` также можно удалить. Настройки виджета находятся в `HKEY_CURRENT_USER\Software\TokenStats\Widget`.

## Состав репозитория

В репозитории только готовый `TokenStats.exe` и эта инструкция. Релизный архив содержит те же два файла. Исходники, тесты и служебные файлы сборки в поставку не входят.
