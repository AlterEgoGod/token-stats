# TokenStats

Windows-приложение для просмотра оставшейся квоты Codex в трее и виджете. Требуются Windows 10/11, .NET Framework 4.8 и установленный Codex с выполненным входом через ChatGPT. Показатели означают процент квоты, а не количество токенов.

## Запуск и установка

После сборки в `dist` находятся только два файла:

- `TokenStats.exe` — запуск без установки, все ресурсы встроены.
- `TokenStats-Setup.exe` — установка для текущего пользователя без прав администратора, с ярлыками в меню «Пуск» и на рабочем столе и записью в «Установленных приложениях» Windows.

Для установки и удаления сначала закройте TokenStats через меню трея. Удаление доступно через параметры Windows. Пользовательские настройки сохраняются.

Если Codex не найден автоматически, создайте рядом с приложением необязательный `codex-path.txt` с полным путём к `codex.exe`. Это единственный случай, когда может понадобиться отдельный файл настройки.

## Использование

Левая кнопка по значку трея открывает виджет, правая — меню. Кнопка в верхнем правом углу разворачивает или сворачивает окно. Виджет можно перетаскивать; прилипание к краям и углам отключается в меню. Размер выбирается автоматически для HD, Full HD, QHD и 4K.

Тема следует теме приложений Windows. При первом запуске язык следует системе: русский для русской Windows, английский для остальных. Выбранный вручную язык сохраняется через «Язык → Русский / English».

Обычно данные обновляются каждые 30 секунд. После ошибки повтор выполняется через 10 секунд после окончания предыдущего запроса; запрос может ожидать ответ до 30 секунд. Браузер автоматически не открывается. При истёкшей сессии нужен ручной вход через кнопку «Войти через ChatGPT».

Для Business Premium основной показатель — недельный лимит, для остальных тарифов — пятичасовой. В развёрнутом окне порядок всегда один: 5 часов, затем неделя. Прочерк или вопросительный знак означают отсутствие актуальных данных. Меню «Лимиты тарифного плана» открывает https://chatgpt.com/settings/usage?tab=overview.

Enter/Space — раскрыть или активировать выбранную кнопку, Tab/Shift+Tab — выбор кнопки, Escape — свернуть или скрыть, F5 — обновить.

Обновления проверяются вручную через GitHub Releases репозитория AlterEgoGod/token-stats с проверкой контрольной суммы и версии EXE.

## Сборка и проверка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

Скрипт использует компилятор .NET Framework из Windows, запускает тесты и создаёт оба EXE. Скачивание зависимостей при сборке не требуется. Предупреждения компилятора считаются ошибками.

- `src` — код приложения.
- `tests` — проверки квот, виджета и обновлений.
- `assets` — текущая иконка, исходная геометрия Reicon, её лицензия и генератор.
- `Setup.cs` — оболочка однофайлового установщика.
- `dist` — актуальная поставка; не входит в Git.
- `.build` — временные результаты проверок; можно удалить, следующая сборка создаст их заново.

Дополнительные проверки:

```powershell
.build\TokenStats.Check.exe --preview-en --self-test
.build\TokenStats.Check.exe --smoke-test --preview-light
.build\TokenStats.Check.exe --smoke-test --preview-en --preview-dark
```

Smoke-проверки используют демонстрационные данные и сохраняют изображения только в `.build`; они не устанавливают приложение и не изменяют настройки виджета.

Шрифт — системный Segoe UI. Иконка — Bolt из Reicon; MIT-лицензия встроена в EXE и сохранена в `assets/REICON-LICENSE.txt`. Прочие сторонние шрифты и пакеты в проект не включены.
